Eight-month security internship at Schneider Electric, in Bengaluru.

## The work

Penetration testing across web applications and network infrastructure, vulnerability assessments against industry standards, and security testing on industrial control systems.

Findings documented and walked through with the development teams that had to fix them.

## On ICS

Industrial control systems are the part that changes how you test. IT security assumes confidentiality first; in an ICS environment availability comes first, because the system is attached to physical equipment that is currently doing something.

A scan that would be routine against a web application can knock over a device that has been running untouched for years and was never built to be probed. So the testing is more careful, the scoping conversations are longer, and "we could exploit this" and "we should exploit this here" are two different sentences.
